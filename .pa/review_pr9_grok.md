## High

**`src-tauri/src/store` and `src-tauri/src/store.rs` can run at the same time.** `Seam::of_path` (`src-tauri/src/workers/lane_guard.rs` 58–66) treats the seam as the exact file `src-tauri/src/store.rs` or a path under `src-tauri/src/store/`. After trailing slashes are removed (`normalize_path`, 77–79, and `normalize_scopes`, `src-tauri/src/store/continuous.rs` 1012–1014), the directory itself is `src-tauri/src/store`. That string is not the file and does not start with `src-tauri/src/store/`, so it occupies no lane.

`paths_overlap` (85–90) also misses the pair: `src-tauri/src/store.rs` does not start with `src-tauri/src/store/`. There is no block and no warning. `dispatch_order` uses that same overlap test (252–260), so a plan that lists the directory and a plan that lists `store.rs` get no ordering edge either.

Admission allows both tasks. `normalize_scopes` (1015–1031) accepts the directory. `scopes_conflict` (1057–1072) does not treat it as the same scope as `src-tauri/src/store.rs`: `strip_prefix` yields `.rs`, which is not a `/` boundary, and `owns_seam` is true only for the file. When it breaks: task A owns `src-tauri/src/store` (or `src-tauri/src/store/` or `SRC-TAURI/SRC/STORE`), task B owns `src-tauri/src/store.rs`, both are claimed, and both call `launch_worker`. Both reservations succeed. The tests never declare the directory path, so they stay green.

## Low

**Dot segments are classified from the raw string.** `normalize_path` (72–80) only strips a leading `./` and trailing slashes. `src-tauri/src/./store.rs` is not the store seam and does not overlap `src-tauri/src/store.rs`. `src-tauri/src/store/../api.rs` is classified as `st` because it starts with `src-tauri/src/store/`, and it does not overlap `src-tauri/src/api.rs`. Current admission rejects `.` and `..` (`continuous.rs` 1018–1020), so `refuse_lane_conflicts` does not see these on tasks created through `create_continuous_task`. `dispatch_order` does not go through that check. It has no production caller yet; a later scheduler that passes unnormalized plan paths will both miss the real seam and block the wrong one.

**A non-seam overlap warning is dropped if the worker is already spawned and the launched-transition then fails.** In `launch_worker` the warning is written only after `mark_development_run_launched` (`src-tauri/src/workers/development.rs` 168–197). The caller sees the reconciliation error from `with_launch_reconciliation`.

**The new claim test stops before retry actually releases the lane.** `the_guard_clears_once_the_holding_package_is_finished` (`lane_guard.rs` 861–885) fails the holder run and asserts the running claim still blocks. `checkpoint_continuous_task(..., "retry")` (`continuous.rs` 613–615, 665–674) requires that failed run, then sets the task to `open` and clears the claim.
